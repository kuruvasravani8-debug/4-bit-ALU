# 4-bit ALU Design - Project 14

## 📌 Description
This project implements a **4-bit Arithmetic Logic Unit (ALU)** using Verilog HDL. 
It is a fundamental building block of CPU that performs arithmetic and logical operations.

Designed and verified as part of my VLSI Learning Journey.

## ⚙️ Operations
| Select (sel) | Operation |
|---|---|
| 000 | ADD (A + B) |
| 001 | SUB (A - B) |
| 010 | AND |
| 011 | OR |
| 100 | XOR |
| 101 | NOT A |
| 110 | Shift Left |
| 111 | Shift Right |

## 💻 Tech Stack
- Language: Verilog HDL
- Tools: Xilinx Vivado / ModelSim
- Concepts: Combinational Logic, Case Statement

## ✅ Output
- `carry` - Carry flag for ADD/SUB
- `zero` - Zero flag when result is 0
- `result` - 4-bit output
